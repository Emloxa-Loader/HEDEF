1. Masa / Koltuk Şınavı

3 Set x 8–10 Tekrar
Ellerini sabit bir masa veya koltuk kenarına omuz genişliğinde koy. Vücudunu topuktan başa kadar düz tut. Göğsünü yüzeye yaklaştırıp kontrollü it.

2. Sandalyeye Oturup Kalkma (Box Squat)

3 Set x 10–12 Tekrar
Arkana sandalye al. Ayaklar omuz genişliğinde açık. Kalçanı sandalyeye hafifçe değdirip kontrollü ayağa kalk. Dizlerini içe bükme.

3. Kapı Eşiğinde Çekiş (Doorframe Row)

3 Set x 10 Tekrar
Kapı pervazını iki elinle tut, ayaklarını yaklaştır ve geriye yaslan. Sırtını ve pazularını sıkarak göğsünü pervaza doğru çek.

4. Köprü Hareketi (Glute Bridge)

3 Set x 12 Tekrar
Sırtüstü uzan, dizlerini büküp ayak tabanlarını yere bas. Topuklardan güç alarak kalçanı yukarı kaldır, tepe noktada kalçanı 1 saniye sık ve indir.
